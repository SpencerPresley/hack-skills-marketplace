OPTION B FRESH-SESSION TECHNIQUE (per Phase 1 `01-03-SUMMARY.md`):

To observe SessionStart firing without disrupting the planner/orchestrator session:
1. Open a SEPARATE terminal (preserves the current claude session if any).
2. Run `claude` to start a fresh session.
3. SessionStart hook fires on the `startup` matcher.
4. Observe Claude's behavior — does the first response reference trust model, operating model, or expert intuitions? (Direct evidence: ask Claude "what context did you receive at session start?")
5. Exit the fresh session.

POSITIVE UAT PROCEDURE (per prompt):

1. In the fresh claude session (or any session with hack-skills-router installed), submit the positive prompt verbatim.
2. Observe Claude's response. UserPromptSubmit hook fires; nudge content is injected as additional context for THIS prompt.
3. Evidence Claude saw the nudge: Claude's response references one or more of the 3 nudge bullets — "confirm scope is authorized", references "Skill(hack-skills-router)" or "expert intuitions" or "boundary conditions a baseline AI tends to miss".
4. If Claude responds normally without any of those markers, the nudge may not have fired. Re-check the cache refresh; check `~/.claude/plugins/cache/.../nudge.sh` matches the working-tree version.

NEGATIVE UAT PROCEDURE (per prompt):

1. Submit the negative prompt verbatim.
2. Observe Claude's response.
3. Evidence the nudge did NOT fire: Claude's response is a normal answer to the prompt with NO security framing, NO mention of authorization scope, NO mention of `Skill(hack-skills-router)`, NO mention of expert intuitions or boundary conditions. The response should look exactly like a baseline Claude response.

CRITICAL: nudge content reaches Claude via context injection, not via Claude printing it. Claude is NOT supposed to echo the nudge text back to the user. Instead, the nudge text becomes part of Claude's working context for that turn — so Claude's RESPONSE shows the influence of having seen the nudge (security framing, scope confirmation, references to the router). For the negative cases, look for the ABSENCE of those influences.
